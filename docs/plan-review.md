# 任务分配计划审阅

进度306增加本地分配草稿、审阅快照和明确确认。它复用现有指挥观察、分配协议与世界校验，适用于园区、月面和海岸。每份草稿最多8项当前可分配任务，同一任务、同一设备各出现一次。后续依赖任务需待条件满足后另行规划。

## 操作

从控制台工具栏的“任务计划审阅”打开面板，或使用 `#command-plan`。切换到外部指挥模式并暂停世界后，可逐项选择任务与候选设备、加入草稿。草稿列出任务、设备、目标、所需能力、优先级、截止步及候选报告年龄等已有信息。

“生成审阅快照”核对全部候选，记录当前仿真步、世界版本、指挥模式与执行方式。它与加入、移除或撤销草稿一样，只修改本页的计划状态，不发送分配指令。世界或候选变化时，原审阅状态失效，需要重新审阅。

点击“确认并逐条提交”后，每项均使用现有指挥分配接口；每次写入前检查当前候选，服务端再按实际任务、设备、路线、材料和通信条件校验。每条响应同步后，再核对世界版本是否只增加了本条请求产生的一个版本。世界推进、其他操作者介入、模式改变、拒绝、失败或响应未确认时，后续条目停止发送。

这是逐条提交流程，没有将多项任务包装成原子事务。已经接受的前序分配不会因后序失败而回滚。即使提交回执为“在途”，通信仍可能在之后失败；面板分别显示提交时回执和当前保留世界记录中的状态，不将排队称为任务完成。

## 撤销与停止

- “撤销未提交草稿”只清除本地计划，不改变世界。
- 提交过程中，“停止后续提交”保留当前请求的核对流程，跳过尚未发送的条目；它不撤回当前网络请求或已经排队的指令。
- 已接受分配应在原“任务指挥”面板，按当前分配版本撤回。已结束提交的计划可清除本地记录，再为剩余候选新建草稿；世界中的指令和事件仍然保留。

响应丢失时保留未确认状态和已知请求编号，并停止后续条目。同步后的世界记录可能已经显示该请求被接受；页面不会因此自动重新发送或继续整份计划。HTTP明确拒绝则显示未提交。意外异常保留不确定状态，避免把潜在的实际写入当作没有发生。

草稿不含凭据，属于当前页面的本地状态。只读、单体、导入和历史范围不读取或展示草稿明细。切换运行后，旧请求的反馈与锁不会用于新的运行。草稿及审阅信息不写入世界回放；回放保留实际协议请求、分配版本与事件，不能凭它认证某人曾审阅页面。

## 服务能力与可选条件

远程计划要求 `/health` 明确提供 `features.decisionPreconditions: 1`。不支持该能力的旧服务仍可使用原有接口，计划提交控件保持禁用，避免把被忽略的可选参数当作已生效。

`POST /sessions/:id/coordinator/decisions` 支持两个可选字段：

```json
{
  "requestId": "ui-plan-1",
  "taskId": "inspect",
  "agentId": "drone-1",
  "observedTick": 0,
  "expectedRevision": 0,
  "requirePaused": true
}
```

`expectedRevision` 为非负整数；新请求的版本不符返回409 `world_revision_changed`。`requirePaused` 为布尔值，值为真且世界运行中时，新请求返回409 `world_running`。这些拒绝发生在进入世界分配逻辑前，不产生新指令记录或世界版本。已有请求先保留原有归属校验；相同所有者、相同指令的合法重试仍可取得已有回执，不会因旧条件而再创建一次分配。其他节点不能接管该请求编号。

不传这些字段的既有SDK保持原行为。字段只用于HTTP入口条件，不进入物理世界、单体观察或回放格式；Rust内核、Protobuf、场景定义与物理二进制未改变。网页对每项确认请求都携带已知世界版本与暂停条件，并使用 `ui-plan-` 请求编号以便核对。

## 验证范围

- 单元与React服务端渲染验证零写入草稿／审阅／撤销、具体目标信息、8项上限与唯一设备、审阅失效、暂停及范围守卫、停止后续条目、提交回执与当前记录分离。隐藏范围使用会抛错的候选及草稿属性验证不读取明细；实际页面桥接代码检查版本、暂停条件和请求编号传递。
- 园区并行、月面设施、海岸救援三个配置，分别运行两种物理模式和三种外部指挥模式，共18个完整原生HTTP任务，完成132项任务，3,586帧持久回放均验证通过。正向组显式采用范围150、延迟2、无丢包与无遮挡配置，结果不代表所有弱通信条件。
- 独立负向检查覆盖同一步其他操作者先分配、实际提交后丢响应、旧条件下取得同请求回执、其他节点重试被拒绝、进行中停止、在途回执之后的链路中断失败、运行状态条件和非法条件字段。
- 当前本地独立世界进程服务另以真实前端设置载荷和计划控制器运行：草稿／审阅／撤销零写入，首份2项审阅计划确认后共完成园区6项任务，T130结束，137帧回放有效。该例采用自动执行设备模式，不是独立设备进程或浏览器画面验收。
